# Stock Market Data Analysis 📈

This project analyzes historical stock data for the top 500 companies over the last 5 years using Yahoo Finance data.

## 📊 Objectives
- Clean and preprocess raw stock data
- Visualize key metrics (price trends, volume, moving averages)
- Identify performance patterns across sectors

## 🛠 Tools Used
- PowerBI (Visualization and Data cleaning)
- Yahoo Finance

## 🧠 Insights
- Identified top and bottom-performing stocks
- Observed post-COVID recovery trends across sectors
- Evaluated volatility metrics for risk-aware investment
